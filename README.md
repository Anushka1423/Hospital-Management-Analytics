# 🏥 Hospital Management Analytics Dashboard

## 📌 Project Overview

This project is an end-to-end Hospital Management Analytics solution built using **MySQL** and **Power BI**. It demonstrates SQL querying, data analysis, dashboard creation, and business insights from hospital data.

---

## 🛠️ Tools & Technologies

- MySQL
- Power BI
- SQL
- CSV Dataset
- Git & GitHub

---

## 📊 Dashboard Features

- Total Patients KPI
- Total Doctors KPI
- Total Departments KPI
- Total Appointments KPI
- Bed Availability Analysis
- Patients by Blood Group
- Patients by Gender
- Doctors by Department
- Interactive Department Slicer
- Interactive Gender Slicer

---

## 📈 Business Analysis

The project includes **30 SQL business queries**, such as:

- Total number of patients
- Average patient age
- Doctors in each department
- Highest consultation fee
- Blood group distribution
- Gender-wise patient analysis
- Department-wise doctor count
- Appointment statistics
- Bed availability analysis
